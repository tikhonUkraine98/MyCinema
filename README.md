# MyCinema

Персональна локальна бібліотека серіалів і відеоплеєр.

## Швидкий запуск

1. Завантажте цей репозиторій через **Code → Download ZIP** та розпакуйте.
2. Відкрийте `index.html` у Chrome або Edge. Для плеєра окремий сервер не потрібен.
3. Щоб знайти серіали, відкрийте **Пошук** і введіть власний **TMDB API Key** або **API Read Access Token** в налаштуваннях.
4. Для перегляду додайте доступні вам прямі посилання на MP4/WebM в **Бібліотека → Додати серіал**.

## Що вміє

- Локальна бібліотека, сезони, епізоди, список відтворення;
- Прогрес перегляду, автоперехід, редагування джерел;
- Пошук серіалів через [TMDB](https://www.themoviedb.org) та перегляд метаданих;
- **Каталог без введення назви**: популярні, новинки, жанри, рейтинг, країна й тип доступу;
- Знайдені через TMDB серіали показуються після перевірки даних про доступність через JustWatch для обраної країни;
- Офіційні стримінгові платформи за даними TMDB / JustWatch — **не** прямі відеофайли;
- **Завантаження перевірених прямих відеофайлів**: зберігання однієї серії або сезону в обрану папку Chrome/Edge, потоковий запис, прогрес, скасування та без перезапису готових файлів;
- Обране, імпорт та експорт JSON;
- Один HTML-файл, без збірки, фреймворків та обов'язкового бекенду.

## Відео: автоматична перевірка джерел

У розділі **Бібліотека** спочатку ввімкнено **«Показувати лише серіали з перевіреною серією»**. Першу серію кожного з доданих сезонів застосунок перевіряє автоматично, решту — за кнопкою **«Перевірити всі серії»**. Серіали без підтверджених джерел можна переглянути, вимкнувши фільтр.

Перевірка виконується через нативний HTML5-відтворювач без передавання URL нашому серверу:
- отримання метаданих медіафайлу;
- відсікання коротких роликів (< 120 с), типових для рекламних заглушок;
- тест вибіркового фрагмента приблизно на 55% тривалості;
- невдалі/невизначені запити не позначаються як підтверджені.

Для обмеження навантаження одночасно перевіряються не більше **двох** відео, а автоматична перевірка охоплює не більше **24** нових URL за відкриття бібліотеки. Кнопка перевірки всіх серій працює партіями до **60** URL. Результати тимчасово кешуються в браузері та періодично потребують повторної перевірки.

**Обмеження:** ця перевірка підтверджує лише доступність окремих фрагментів відео, а не можливість завантажити весь файл, дозвіл на його копіювання чи наявність кожного епізоду. TMDB не дає прямих відеоджерел. Для автоматичного пошуку нових джерел потрібні додаткові провайдери з дозволеними API. Не використовуйте це для обходу платної авторизації.

## Перехід зі старого плеєра

У старій версії `player.html` натисніть **Експорт**. У новій — **Імпорт** і виберіть той самий JSON. Або збережіть цей `index.html` під ім'ям `player.html` поруч зі старим: браузер може автоматично прочитати ту саму локальну бібліотеку (залежить від правил `file://`).

**У публічному репозиторії немає посилань на сторонні серіали, токенів чи платних потоків.** Власні джерела залишаються локально у браузері або у ваших резервних копіях.

## Каталог: знаходити серіали, не знаючи їх назв

Натисніть **«Каталог серіалів»**. Введіть TMDB-ключ у **«Налаштування»**. Потім оберіть країну (за замовчуванням UA), тип доступу (безкоштовно, підписка, оренда, купівля), жанр, рейтинг або сортування.

TMDB відбирає серіали за зазначеними умовами, а застосунок **для кожної картки перевіряє** API `/tv/{id}/watch/providers`. Без підтвердженого запису про платформу серіал не відображається у відфільтрованому каталозі. Списки завантажуються сторінками. **Це перевірка наявності платформи, а не успішного відтворення та не перевірка можливості завантаження.**

У **«Бібліотека»** за замовчуванням увімкнений інший, суворіший фільтр: тут показані лише серіали, для яких прямий відеофайл пройшов перевірку отримання метаданих і кадрів. Це також не гарантує повного завантаження.

## Як завантажити власні доступні відеофайли

У розділі **«Бібліотека»** додайте прямі адреси MP4/WebM, до яких у вас є дозвіл на доступ і копіювання. Перевірте їх, відкрийте серію та натисніть **«Завантажити серію»** або **«Завантажити сезон»**.

- Потрібен сучасний **Chrome / Edge** з підтримкою File System Access API та безпечний контекст.
- Оберіть папку. Для сезону застосунок створює підпапки із назвою серіалу та номером сезону.
- Файли записуються **потоково**, без збирання всього відео в RAM.
- Якщо сторонній сервер блокує CORS, має платну авторизацію, DRM, не повертає доступний MP4/WebM або видає заглушку, завантаження **не вдасться**. Програма не обходить ці обмеження.
- Вже наявні ненульові файли не перезаписуються, а пропускаються. Після перерваного завантаження файл може залишитися порожнім; перевірте папку.

**Що поки не готове:** автоматичний пошук *прямих* відеоджерел для всіх назв у TMDB. Універсального публічного API всіх завантажуваних серіалів немає. Наступний етап — підключати окремі дозволені провайдери, які повертають дійсні адреси й умови завантаження. Стримінгова доступність TMDB сама по собі такої інформації не містить.

## API та безпека

Отримайте особистий ключ в [налаштуваннях TMDB](https://www.themoviedb.org/settings/api). Ключ або токен додається у власному браузері, не в коді GitHub. Він зберігається у `localStorage`, тому будь-який JavaScript на тому самому origin може його прочитати. Для публічного хостингу та спільного використання замість цього потрібен бекенд для зберігання секретів. Не публікуйте власний API-токен у репозиторії чи скриншотах.

TMDB використовується для метаданих, постерів і списків сезонів, **не** для відеофайлів. Дані про провайдерів можуть бути неповними та відрізняються за країнами.
