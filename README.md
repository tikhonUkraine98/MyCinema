# MyCinema

Персональна локальна бібліотека серіалів і відеоплеєр.

## Швидкий запуск

1. Завантажте цей репозиторій через **Code → Download ZIP** та розпакуйте.
2. На Windows запустіть **`start.cmd`** або відкрийте `index.html` у Chrome/Edge. Окремий сервер не потрібен.
3. Щоб знайти серіали, відкрийте **Пошук** і введіть власний **TMDB API Key** або **API Read Access Token** в налаштуваннях.
4. Для перегляду додайте доступні вам прямі посилання на MP4/WebM в **Бібліотека → Додати серіал**.

## Що вміє

- Локальна бібліотека, сезони, епізоди, список відтворення і відкриття MP4/WebM прямо з диска;
- Прогрес перегляду, автоперехід, редагування джерел;
- Пошук серіалів через [TMDB](https://www.themoviedb.org) та перегляд метаданих;
- **Каталог без введення назви**: популярні, новинки, жанри, рейтинг, країна й тип доступу;
- **PeerTube**: федеративний пошук відкрито ліцензованих довгих відео і пряме MP4/WebM за наявності;
- **Основний каталог показує всі серіали TMDB незалежно від року та наявності MP4**. Вибір відеоджерела — окрема операція;
- Офіційні стримінгові платформи за даними TMDB / JustWatch — **не** прямі відеофайли;
- **Завантаження перевірених прямих відеофайлів**: зберігання однієї серії або сезону в обрану папку Chrome/Edge, потоковий запис, прогрес, скасування та без перезапису готових файлів;
- Обране, імпорт та експорт JSON;
- Один HTML-файл, без збірки, фреймворків та обов'язкового бекенду.

## Відео: автоматична перевірка джерел

У розділі **Бібліотека** спочатку ввімкнено **«Показувати лише серіали з перевіреною серією»**. Першу серію кожного з доданих сезонів застосунок перевіряє автоматично, решту — за кнопкою **«Перевірити всі серії»**. Серіали без підтверджених джерел можна переглянути, вимкнувши фільтр.

Перевірка виконується через нативний HTML5-відтворювач без передавання URL нашому серверу:
- отримання метаданих медіафайлу;
- відсікання коротких роликів (< 120 с), типових для рекламних заглушок;
- тест вибіркового фрагмента приблизно на 55% тривалості;
- невдалі/невизначені запити не позначаються як підтверджені.

Для обмеження навантаження одночасно перевіряються не більше **двох** відео, а автоматична перевірка охоплює не більше **24** нових URL за відкриття бібліотеки. Кнопка перевірки всіх серій працює партіями до **60** URL. Результати тимчасово кешуються в браузері та періодично потребують повторної перевірки.

**Обмеження:** ця перевірка підтверджує лише доступність окремих фрагментів відео, а не можливість завантажити весь файл, дозвіл на його копіювання чи наявність кожного епізоду. TMDB не дає прямих відеоджерел. Для автоматичного пошуку нових джерел потрібні додаткові провайдери з дозволеними API. Не використовуйте це для обходу платної авторизації.

## Перехід зі старого плеєра

У старій версії `player.html` натисніть **Експорт**. У новій — **Імпорт** і виберіть той самий JSON. Або збережіть цей `index.html` під ім'ям `player.html` поруч зі старим: браузер може автоматично прочитати ту саму локальну бібліотеку (залежить від правил `file://`).

**У публічному репозиторії немає посилань на сторонні серіали, токенів чи платних потоків.** Власні джерела залишаються локально у браузері або у ваших резервних копіях.

## PeerTube — друге реальне джерело відео

У MyCinema натисніть **PeerTube відео** або кнопку **Пошук у PeerTube** на картці TMDB. Пошук використовує публічний федеративний індекс SepiaSearch, тому не потребує API-ключа.

1. Введіть назву або тему.
2. Застосунок показує публічні ролики тривалістю не менше 15 хвилин, для яких автор позначив CC BY, CC BY-SA або Public Domain.
3. Натисніть **Перевірити MP4 і додати**. Програма звернеться до оригінального PeerTube-сервера, перевірить ліцензію та дозвіл завантаження, прямий MP4/WebM і доступність фрагмента відео.
4. Якщо перевірка пройшла, відео потрапить у бібліотеку з інформацією про його походження. Плеєр відкриється одразу; завантаження доступне через **Завантажити серію**, якщо браузер і сервер його дозволяють.

**PeerTube — це відеохостинг користувацьких публікацій, а не безкоштовна база сучасних комерційних серіалів.** Збіг назви з TMDB не підтверджує, що відео є офіційною серією. Заявлену ліцензію потрібно звіряти з першоджерелом. Відео без явної відповідної ліцензії та без прямого доступного файлу не додаються.

Офіційна документація: [PeerTube REST API](https://docs.joinpeertube.org/api-rest-reference.html), [VideoFile](https://docs.joinpeertube.org/api-rest-reference/api/models/videofile.html). Залежно від конкретного PeerTube-сервера CORS, доступність файлів та пошукова індексація можуть відрізнятися.

## Автоматичний пошук реально доступних відео

**Без API-ключа:** натисніть **«Пошук відкритих файлів» → «Переглянути відкритий відеоархів»**. MyCinema сканує публічний Internet Archive за телевізійними записами, відкриває метадані кожного кандидата, перевіряє заявлену відкриту ліцензію (CC0, Public Domain Mark, CC BY, CC BY-SA), знаходить достатньо великі MP4/WebM, виконує запит HEAD і тест вибіркового фрагмента відео. Лише результати, які пройшли ці перевірки, потрапляють у список архіву. Можна гортати сторінки; результати обмежені доступними й коректно розміченими записами.

**За назвою:** у тому самому вікні введіть назву, отримайте архівні збіги та натисніть **«Перевірити файли»**. Кнопка **«Додати до бібліотеки»** створить локальний запис, відкриє плеєр і збереже ліцензію та джерело у резервній копії. Якщо в матеріалі багато файлів, використовуйте **«Заповнити форму всіма файлами»**, щоб спочатку перевірити відповідність файлів епізодам.

**З TMDB-ключем:** режим **«Усі серіали TMDB»** є режимом за замовчуванням. Він показує сучасні й класичні серіали за жанром, рейтингом, роком та популярністю без залежності від Internet Archive. Кожна картка містить окрему дію **«Шукати відкриті відео»**, що запускає перевірку можливості отримати відкриті MP4/WebM для конкретної назви. Це не гарантує наявності такого файлу.

Режим **«Лише з перевіреним відкритим файлом»** залишено як додатковий суворий фільтр: він може показати нуль результатів, оскільки Internet Archive не є джерелом більшості сучасних серіалів. Режим **«Доступні на стримінгових платформах»** показує серіали за даними JustWatch через TMDB — **це інформація про платформу перегляду, а не можливість завантаження MP4**.

**Межі достовірності:** позначка ліцензії у завантажених кимось метаданих не гарантує, що завантажувач мав права на матеріал; перевіряйте джерело й умови використання. Отримання метаданих та фрагмента відео не гарантує цілісності всього файлу. Більшість сучасних серіалів, захищених авторським правом, не мають вільної для завантаження копії: каталог може бути порожнім, і це очікувана поведінка.

## Офлайн-перегляд завантажених серій

У плеєрі натисніть **«Відкрити файли з диска»** і виберіть один або кілька файлів MP4/WebM (наприклад, цілий скачаний сезон із папки). Плеєр відсортує файли за назвами, створить локальний список, дозволить перемикати серії, автоматично переходити до наступної та запам'ятає часову позицію кожного файлу.

Файли відкриваються без інтернету через локальні URL, не завантажуються на сторонній сервер. Самі браузерні дозволи на файли **не переживають перезапуск**: після нового відкриття MyCinema потрібно знову вибрати локальні файли, але прогрес за назвами/розмірами/датами файлів зберігається локально.

## Завантаження і відновлення

У Chrome/Edge використовується File System Access API. Завантаження виконується частинами потоку в обрану папку без накопичення всього відеофайлу в пам'яті. У випадку переривання можна повторити команду для того самого файлу: якщо сервер підтримує `Range` та повертає очікуваний загальний розмір, запис продовжиться з місця зупинки. Якщо безпечне продовження не підтримується, програма не перезаписує існуючий файл. Повний розмір звіряється після завершення.

## Каталог: знаходити серіали, не знаючи їх назв

Натисніть **«Каталог серіалів»**. Введіть TMDB-ключ у **«Налаштування»**. Потім оберіть країну (за замовчуванням UA), тип доступу (безкоштовно, підписка, оренда, купівля), жанр, рейтинг або сортування.

TMDB відбирає серіали за умовами фільтрів і показує картки без додаткової перевірки відеофайлів. У спеціальному режимі платформ застосунок використовує API `/tv/{id}/watch/providers` і відбирає результати, для яких зазначено платформи у вибраній країні. Списки завантажуються сторінками. **Відсутність MP4 не приховує серіал в основному каталозі.**

У **«Бібліотека»** за замовчуванням увімкнений інший, суворіший фільтр: тут показані лише серіали, для яких прямий відеофайл пройшов перевірку отримання метаданих і кадрів. Це також не гарантує повного завантаження.

## Як завантажити власні доступні відеофайли

У розділі **«Бібліотека»** додайте прямі адреси MP4/WebM, до яких у вас є дозвіл на доступ і копіювання. Перевірте їх, відкрийте серію та натисніть **«Завантажити серію»** або **«Завантажити сезон»**.

- Потрібен сучасний **Chrome / Edge** з підтримкою File System Access API та безпечний контекст.
- Оберіть папку. Для сезону застосунок створює підпапки із назвою серіалу та номером сезону.
- Файли записуються **потоково**, без збирання всього відео в RAM.
- Якщо сторонній сервер блокує CORS, має платну авторизацію, DRM, не повертає доступний MP4/WebM або видає заглушку, завантаження **не вдасться**. Програма не обходить ці обмеження.
- Вже наявні ненульові файли не перезаписуються, а пропускаються. Після перерваного завантаження файл може залишитися порожнім; перевірте папку.

**Межа покриття:** автоматичний пошук прямих джерел працює через відкриті ліцензовані матеріали Internet Archive. Універсального публічного API, який повертає завантажувані копії всіх сучасних серіалів, немає. Для інших дозволених джерел можна додавати прямі посилання вручну. Стримінгова доступність TMDB не надає MP4, а платні сервіси можуть вимагати офіційний застосунок.

## API та безпека

Отримайте особистий ключ в [налаштуваннях TMDB](https://www.themoviedb.org/settings/api). Ключ або токен додається у власному браузері, не в коді GitHub. Він зберігається у `localStorage`, тому будь-який JavaScript на тому самому origin може його прочитати. Для публічного хостингу та спільного використання замість цього потрібен бекенд для зберігання секретів. Не публікуйте власний API-токен у репозиторії чи скриншотах.

TMDB використовується для метаданих, постерів і списків сезонів, **не** для відеофайлів. Дані про провайдерів можуть бути неповними та відрізняються за країнами.
