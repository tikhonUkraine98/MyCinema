# Перший запуск MyCinema — ключ TMDB і пошук відео

## Навіщо потрібен ключ TMDB

TMDB надає назви, постери, жанри, сезони, описи та перелік офіційних платформ перегляду. Для запитів до його API потрібен особистий ключ. Необхідна лише **реєстрація на TMDB**; для некомерційного використання розробницький API є безкоштовним за умовами TMDB.

1. Відкрийте https://www.themoviedb.org/settings/api і увійдіть до свого облікового запису.
2. У вкладці **API** за потреби подайте заявку **Request an API Key → Developer** та прийміть умови використання.
3. Скопіюйте **API Key (v3)** або **API Read Access Token**.
4. У MyCinema відкрийте **Налаштування** та вставте ключ.
5. Натисніть **Зберегти**; каталог повторить запит.

TMDB API Key не дає доступу до MP4-файлів, а TMDB watch providers показує платформи, **не** прямі відеопосилання. Не додавайте свій ключ до публічного GitHub, у скриншоти або в чати.

## Без ключа

Відкрийте **Пошук відкритих файлів → Переглянути відкритий відеоархів**. Тут використовується публічний Internet Archive API і TMDB-ключ не потрібен.

Пошук обмежений матеріалами з вказаною відкритою ліцензією й доступними MP4/WebM. Замість повідомлення «нічого не знайдено» застосунок показує, на якому етапі записи відхилено (ліцензія, файл, мережа чи відтворення). Він може не знайти нічого на певній сторінці — це не означає відсутності матеріалів у всьому архіві.

## Обмеження

- Відкрито позначена ліцензія у метаданих Archive не гарантує, що завантажувач мав право поширювати контент; перевіряйте походження.
- Відео-проби і HTTP-Range показують часткову технічну доступність, не гарантію повної передачі.
- Результат у загальному каталозі TMDB не гарантує доступність MP4.
- Сервери сторонніх джерел можуть тимчасово відхиляти запити або накладати CORS/ліміти.
