Перевірка джерел ще не виконана.

Попередня перевірка пробує відкрити відео й відсіює короткі рекламні заглушки. Вона не гарантує, що весь файл завантажиться. Для пошуку нових джерел потрібні окремі дозволені провайдери.

Для нових серіалів використовуй прямі MP4/WebM-посилання, до яких маєш право доступу. Експорт створює резервну копію адрес і прогресу перегляду.

Додати серіал

Додай один сезон. Інші сезони того самого серіалу можна додати пізніше, вказавши ту саму назву.

Для автоматичного режиму адреса має містити позначку серії на кшталт s01e01. Плеєр змінить e01 на e02, e03 тощо.

Налаштування пошуку

Для пошуку серіалів потрібен власний TMDB API Key або API Read Access Token. Не зберігай ключ у публічному GitHub.

Ключ зберігається у localStorage браузера. Для персонального локального використання; на спільному комп'ютері не рекомендується.
